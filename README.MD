
# AI Usage Impact Analysis

## Project Overview
This project analyzes AI usage among students and its relationship with academic performance and study habits.

## Dataset
- 8,000 student records
- 29 features

## Tools & Technologies
- Python
- Pandas
- NumPy
- Excel
- Power BI

## Work Completed
1. Collected multiple datasets.
2. Merged datasets into one Excel file.
3. Loaded the merged dataset using Python.
4. Inspected dataset structure, columns, and data types.
5. Checked for missing values and duplicate records.
6. Cleaned column names and text values.
7. Handled missing values.
8. Exported the cleaned dataset to Excel.

## Project Files
- `mergedata.py` - Dataset merging
- `mergedata.xlsx` - Merged dataset
- `cleandata.py` - Data cleaning
- `cleaned_dataset.xlsx` - Cleaned dataset
